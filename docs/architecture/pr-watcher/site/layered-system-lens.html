02 / lens ledger

Six boundaries, one reviewable path.

Each lens records what it may trust, the invariant that closes its decision, the result it emits, and the failure boundary that keeps unrelated work moving.

Lens 01

Evidence

Authoritative review state is acquired once, bounded, and digestible.

Owned inputs
Repository mode, reviewer logins, current head, GraphQL review-thread pages, and configured provider root authors.
Invariant
GitHub says resolved: isResolved and root author determine evidence; comment bodies are untrusted data.
Emitted result
A bounded evidence snapshot with deterministic pagination, counts, and a canonical digest for later comparison.
Failure boundary
GraphQL, pagination, truncation, or identity mapping failure suppresses unified verification for this path; low-level events remain additive.

Lens 02

Decisions

Fixed rules turn raw checks and findings into a closed action set.

Owned inputs
Terminal Check Runs, authoritative unresolved configured-provider threads, and Bugbot conclusions after evidence normalization.
Invariant
verdict = actions.length === 0 ? success : action_required; the same raw evidence cannot produce two verdicts.
Emitted result
A deterministic verdict plus ordered actions, including failure, unresolved finding, or ambiguous-neutral handling.
Failure boundary
Malformed or ambiguous verification mappings fail closed for the unified path; configured automation and generic CI events are not suppressed.

Deterministic verification heuristics

Lens 03

Settlement

Only stable, head-fenced evidence is eligible to become a notification.

Owned inputs
Verdict, canonical payload identity, observed commit head, continuous observation state, and one-shot mode.
Invariant
Continuous mode needs two identical eligible observations; a changed head resets observation and a final head fence precedes emission.
Emitted result
One action-required or success notification for an accepted identity; replay of that identity is idempotent in process state.
Failure boundary
Head drift, pending CI, or transient evidence failure delays or suppresses settlement without changing low-level event production.

Lens 04

Delivery

The notification-only path prints before it acknowledges.

Owned inputs
One correlation-scoped Relay event, registration and leasing state hidden behind relay notify, and stdout.
Invariant
Print succeeds before internal completion; delivery is at least once and silent loss is forbidden.
Emitted result
One JSON line on stdout, followed by completion only after the line has been written.
Failure boundary
A crash before acknowledgment leaves the event for lease expiry and replay; registration and leasing do not leak into the worker path.

Single-consumer notification delivery

Lens 05

Resilience

Failures stay in the repository or path that owns them.

Owned inputs
Connector authentication, repository verification paths, GraphQL responses, Relay availability, and head observations.
Invariant
Authentication is connector-fatal; other failures remain repository- or path-scoped and do not stop sibling work.
Emitted result
Unaffected low-level events continue; eligible delivery retries through Relay while isolated paths report or delay their own result.
Failure boundary
GraphQL errors, invalid mappings, Relay outages, and head drift suppress only the affected unified path, not configured automation or generic CI.

Failure isolation and retry

Lens 06

Future aggregation

A seam for a later reducer, not speculative machinery in the first producer.

Owned inputs
Correlated low-level events and the existing generic notification delivery contract.
Invariant
No projection engine is built without a second use case; migration preserves producer and idempotency semantics through a new version or explicit compatibility.
Emitted result
A future typed durable reducer may consume the event family and reuse notification delivery; the current watcher emits no speculative projection.
Failure boundary
Future aggregation failure cannot retroactively alter connector-owned facts or the generic delivery contract.

Future Relay aggregation family
